# harrisonfamily-frontend/

Synthetic sample data laid out like the private family data in the site bucket (`person/`, `family/`, `event/`, `note/`, `place/`, `media/`). It contains no real records, and its shape predates the current contract, so do not build or test against it.

- Publishing new family data: [Refresh the family data](../docs/how-to/refresh-the-family-data.md)
- Why this data stays out of git: [The privacy model for family data](../docs/explanation/family-data-privacy.md)
