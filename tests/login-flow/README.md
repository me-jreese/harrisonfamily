# tests/login-flow/

Playwright suites for sign-in: `login-flow.spec.ts` (the legacy Google path) and `auth-v2.spec.ts` (the auth edge).

**These suites target the live production site by default.** Run them only with io's go-ahead, and only with a test account.

- Prerequisites, environment variables and how to run them: [Run the test suites](../../docs/how-to/run-the-tests.md)
- What the suites cover and their environment: [Repository operations](../../docs/reference/repository-operations.md#test-suites)
- When sign-in fails: [Diagnose sign-in and API failures](../../docs/how-to/diagnose-sign-in-and-api-failures.md)
