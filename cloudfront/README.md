# cloudfront/

`distribution.json` is a sanitized sample of the distribution from before the `scripts/infra/` behavior scripts ran. It is the input of the offline dry runs in `scripts/infra/test/run.sh`, not the live configuration. `scripts/export_workspace_samples.sh` replaces this whole directory from the workspace copy, so change both ([Refresh the sanitized samples](../docs/how-to/refresh-the-sanitized-samples.md)).

- Routing, behaviors and `HFYAppendIndex`: [System architecture](../docs/reference/architecture.md#request-routing), [Edge and origin design](../docs/explanation/edge-and-origin-design.md), [Publish the CloudFront Function](../docs/how-to/publish-the-cloudfront-function.md). Behavior scripts: [Repository operations](../docs/reference/repository-operations.md#cloudfront-behavior-scripts), [Deploy the app stack](../docs/how-to/deploy-the-app-stack.md).
- The "Private data gate" that code comments cite here, `/uploads/*` included: [Identity services](../docs/reference/identity-services.md#private-data-gate-hfy-edge-gate), [Deploy the edge functions](../docs/how-to/deploy-the-edge-functions.md), and [Cut over to authV2 and the private data gate](../docs/how-to/cut-over-to-the-private-data-gate.md) for the order, the state checks and the rollback.
